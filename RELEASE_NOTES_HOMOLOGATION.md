# Homologação R18.46.32

R18.46.32 Homologação: primeira etapa do Assistente IA exclusiva do Administrador, com acesso pela Visão Geral. IA apenas classifica comandos e não dispõe de ferramentas para alterar código, arquivos, SQL ou atualizações. Consultas permitidas: faturamento do dia, consulta e proposta de alteração de custo vigente de ingredientes; alterações somente após confirmação e com auditoria, token de sessão e verificação do valor anterior. Chave de API configurada fora do código pelo ambiente local, sem expor ao navegador; sem chave o assistente permanece desativado. Worker 1.38.4 e schema 34 preservados. Produção inalterada.
