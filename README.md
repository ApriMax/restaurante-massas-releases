# Sistema Restaurante Massas — Atualizações

Repositório público de distribuição do **Sistema Restaurante Massas**.

Este repositório não contém o código-fonte privado do sistema.

Ele é utilizado para publicar:
- manifesto da versão estável;
- notas de atualização;
- links para os pacotes de instalação/atualização;
- hashes SHA-256 para validação do download.

Os pacotes binários são publicados como **GitHub Releases**.
