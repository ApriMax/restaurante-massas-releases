# R18.31

R18.31 preparada: simplifica o lançamento de custos em Gastos com uma caixa opcional, uma linha inicial e unidade automática pelo cadastro; corrige a atualização da lista de itens de custo para sempre usar o catálogo atual; adiciona atualização manual de custos sem gerar gasto financeiro; o App de Gastos passa a permitir vários itens de custo em Digitar gasto com o mesmo fluxo simplificado; alterações de cadastro de itens sincronizam imediatamente o catálogo de custos com o App; corrige também o falso alerta de Worker desatualizado, removendo a referência antiga fixa ao Worker 1.27.0 e usando a versão esperada da própria release.
